# northstar-data

Public market-screener data (JS files that set `window.SCREEN` / `window.NORTHSTAR_BOOKS`) for Benny's NorthStar desk.
Generated from Yahoo Finance (yfinance) approximations by `refresh.sh`; pushed here so the site can fetch fresh data without redeploying.
Not investment advice.

- `data/screen-data.js` – swing screen
- `data/scalp-data.js` – scalp book
- `data/crypto-data.js` – crypto book
